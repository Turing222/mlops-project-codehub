# Assessments

带日期的**时点评估与审计报告**。记录某次评审时的证据、结论与建议，不等同于现行工程规范。

## 如何使用

- 查**当前该怎么做** → 回到 [docs/README.md](../README.md) 的 `standards/`、`workflows/`、`platform/`。
- 查**为什么当时这么改** → 读对应日期的评估文档。
- 评估中的建议已落地 → 把规范写入长期目录，本目录原文保留作历史。

## 命名约定

`{主题}-{类型}-YYYY-MM-DD.md`，例如 `frontend-cicd-assessment-2026-06-14.md`。
